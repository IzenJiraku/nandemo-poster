# なんでもポスター

写真を入れると、映画っぽいポスターになるサイトです。

- ジャンル：青春／韓国映画風／韓国ノワール／ホラー／サスペンス／ロマンス／SF／コメディ／昭和レトロ（「おまかせ」もあり）
- タイトル・サブタイトル・コピー・キャスト・監督・公開日は、自分で入力するか🎲でおまかせ
- 写真はブラウザの中だけで処理し、どこにも送信しません（サーバーなし・ログインなし・無料）
- おまかせで出る人名や映画祭・媒体名はすべて架空です

## 使い方（ローカル）

```
python3 -m http.server
```

を実行して http://localhost:8000 を開きます。ビルドは不要です。

## しくみ

- `app.js`：Canvas での色調加工（色・コントラスト・セピア・スプリットトーン・ブルーム・粒子・周辺減光）と、ジャンル別の文字組み（縦書きを含む）
- `data.js`：おまかせ用のタイトル・コピー・人名・公開日の素材
- フォントは Google Fonts（Noto Sans/Serif JP、Shippori Mincho B1、Zen Maru Gothic、Dela Gothic One、Yuji Syuku、Yuji Boku、Gowun Batang、Noto Sans KR など）
