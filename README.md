# なんでもポスター

写真を入れると、映画っぽいポスターになるサイトです。

- 写真はブラウザの中だけで処理し、どこにも送信しません（サーバーなし・ログインなし・無料）
- おまかせで出る人名・映画祭名・媒体名はすべて架空です

## できること

- **ジャンル 18種**：青春／台湾青春／韓国映画風／韓国ノワール／ミニシアター／フランス映画／ホラー／サスペンス／ミステリー／香港ノワール／ロマンス／SF／ファンタジー／アクション／コメディ／ドキュメンタリー／時代劇／昭和レトロ
- **構図 25種**：王道（下にタイトル）、上にタイトル、中央にドン、縦書き（右・左・中央）、左下に小さく、白枠、上下分割、巨大タイポ、アーチ窓、斜めの帯、キャスト名が上、シネスコ、帯にタイトル、ポラロイド、三枚つづき、丸窓、白抜きの巨大文字、左の帯に縦書き、チケット、フィルム、スイス・グリッド、映画祭マーク＋クレジット、絶賛の声が主役
- **タイトル書体 16種**（明朝・ゴシック・丸ゴ・手書き・筆文字・ドットなど）と **色調 13種**（モノクロ、褪色フィルム、ティール＆オレンジ、デュオトーンなど）。どれも「ジャンルに合わせる」のままでもOK
- **しくみ**：余白・三分割・文字の位置と大きさを重ねて表示し、構図ごとに「なぜこの配置か」を解説。文字の面積と大小の差（ジャンプ率）も出ます。文字や賞マークはドラッグで動かせて、押すと消えます
- 操作は「戻る・おまかせ・保存」の3つだけ。構図はポスター下の ‹ ›、文字はポスターの文字を押して書き換え
- 写真はポスターをドラッグで移動、ピンチ／ホイールで拡大、ダブルタップで元に戻す
- 公開日は最初は今日の日付（↻ で別の日付に）
- **お気に入り（☆）**：ポスターと一緒に「構成」（ジャンル・構図・書体・色調・消した項目・動かした位置）も保存。別の写真に「この構成を使う」で呼び出せます。端末のブラウザ（IndexedDB）にだけ保存されます

## 使い方（ローカル）

```
python3 -m http.server
```

を実行して http://localhost:8000 を開きます。ビルドは不要です。

## ファイル

- `data.js`：おまかせ用のタイトル・コピー・人名・スタッフ・映画祭・公開日の素材とジャンル定義
- `engine.js`：Canvas の色調加工（色・コントラスト・セピア・スプリットトーン・デュオトーン・ブルーム・粒子・周辺減光）と文字組み（縦書き、字間、自動で文字色を変える処理など）
- `layouts.js`：構図（文字と写真の置き方）
- `styles.js`：ジャンルごとの色・書体・装飾、書体と色調の上書き、フォント読み込み
- `app.js`：画面の操作（戻る、カゴ、ドラッグ、保存）
- フォントは Google Fonts（Noto Sans/Serif JP、Shippori Mincho B1、Zen Old Mincho、Klee One、Yuji Boku、Dela Gothic One、Bodoni Moda、Noto Serif TC など）
